# Simple Harmonic Motion — Spring-Mass System

An interactive physics simulation designed to help students explore simple harmonic motion using a spring-mass system.

## 🌐 Live Demo

Explore the simulation:

https://inam-alvi.github.io/inam-alvi-simple-harmonic-motion/

## 📖 About the Project

The Simple Harmonic Motion simulation provides an interactive visual environment for exploring the oscillatory motion of a mass attached to a spring.

The simulation is designed to support the study of:

- Simple harmonic motion
- Spring-mass systems
- Oscillation
- Amplitude
- Displacement
- Velocity
- Acceleration
- Restoring force
- Mechanical energy

## ✨ Features

- Interactive spring-mass visualization
- Real-time oscillation
- Adjustable simulation parameters
- Visual representation of periodic motion
- Exploration of spring-mass behavior
- Interactive physics controls
- Educational learning environment
- Responsive interface
- Designed for students and physics educators

## 🎓 Educational Purpose

This simulation supports physics and STEM education by providing an interactive way to visualize simple harmonic motion and understand the behavior of a spring-mass system.

It can be used as:

- A classroom teaching aid
- A student self-learning resource
- A visual revision tool
- An interactive physics demonstration
- A supplementary resource for physics lessons

## 🛠️ Technologies

## 🚀 How to Use

No installation is required.

Open the live simulation in a modern web browser:
