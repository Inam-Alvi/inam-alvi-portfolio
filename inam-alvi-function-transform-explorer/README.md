# Function Transform Explorer

An interactive mathematics simulation designed to help students explore function transformations through visual graphs and interactive controls.

## 🌐 Live Demo

Explore the simulation:

https://inam-alvi.github.io/inam-alvi-function-transform-explorer/

## 📖 About the Project

The Function Transform Explorer is an interactive mathematics learning tool for exploring how transformations change the position, shape, and orientation of functions.

The simulation helps learners visualize important function transformations, including:

- Translations
- Reflections
- Vertical scaling
- Horizontal scaling
- Changes in function position and shape

Instead of studying transformations only through algebraic rules, learners can observe the effects directly on graphs.

## ✨ Features

- Interactive function graph visualization
- Exploration of function transformations
- Horizontal and vertical translations
- Reflections
- Horizontal and vertical scaling
- Interactive mathematical controls
- Visual comparison of transformed functions
- Real-time graph updates
- Responsive interface
- Designed for students and mathematics educators

## 🎓 Educational Purpose

This simulation supports mathematics and STEM education by providing a visual and interactive approach to understanding function transformations.

It can be used as:

- A classroom teaching aid
- A student self-learning resource
- A visual revision tool
- An interactive demonstration of function transformations
- A supplementary resource for algebra and pre-calculus lessons
