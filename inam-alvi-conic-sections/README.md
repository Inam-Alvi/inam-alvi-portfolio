# Conic Sections

An interactive mathematics simulation designed to help students explore the four fundamental conic sections: circle, ellipse, parabola, and hyperbola.

## 🌐 Live Demo

Explore the simulation:

https://inam-alvi.github.io/inam-alvi-conic-sections/

## 📖 About the Project

The Conic Sections simulation is an interactive mathematics learning tool for exploring the geometric properties and visual forms of the four major conic sections.

It provides a visual environment where learners can investigate:

- Circle
- Ellipse
- Parabola
- Hyperbola

The simulation is designed to make conic sections easier to understand through interactive visualization rather than static diagrams alone.

## ✨ Features

- Interactive visualization of the four conic sections
- Exploration of circle, ellipse, parabola, and hyperbola
- Visual comparison of different conic shapes
- Interactive mathematical controls
- Coordinate-plane visualization
- Educational explanations
- Responsive interface
- Designed for students and mathematics educators

## 🎓 Educational Purpose

This simulation supports mathematics and STEM education by providing an interactive way to explore conic sections.

It can be used as:

- A classroom teaching aid
- A student self-learning resource
- A visual revision tool
- An interactive mathematics demonstration
- A supplementary resource for coordinate geometry
