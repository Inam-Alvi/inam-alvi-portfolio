# VSEPR Builder

An interactive chemistry simulation designed to help students explore VSEPR theory, molecular structures, and molecular geometry.

## 🌐 Live Demo

Explore the simulation:

https://inam-alvi.github.io/inam-alvi-vsepr-builder/

## 📖 About the Project

The VSEPR Builder provides an interactive visual environment for building and exploring molecular structures using Valence Shell Electron Pair Repulsion (VSEPR) theory.

The simulation is designed to support learning about:

- VSEPR theory
- Electron-pair repulsion
- Bonding pairs
- Lone pairs
- Electron-domain geometry
- Molecular geometry
- Molecular shapes
- Bond angles
- Molecular structure

## ✨ Features

- Interactive molecular structure builder
- VSEPR-based molecular geometry exploration
- Bonding-pair and lone-pair visualization
- Interactive electron-domain configurations
- Visual molecular shape demonstrations
- Educational chemistry simulations
- Responsive interface
- Designed for students and chemistry educators

## 🎓 Educational Purpose

This simulation supports chemistry and STEM education by providing an interactive way to visualize how electron pairs around a central atom influence molecular geometry.

It can be used as:

- A classroom teaching aid
- A student self-learning resource
- A visual revision tool
- An interactive chemistry demonstration
- A supplementary resource for lessons on molecular geometry

## 🛠️ Technologies

## 🚀 How to Use

No installation is required.

Open the live simulation in a modern web browser:

https://inam-alvi.github.io/inam-alvi-vsepr-builder/

Select or build different molecular configurations and explore how bonding pairs and lone pairs affect molecular geometry.
