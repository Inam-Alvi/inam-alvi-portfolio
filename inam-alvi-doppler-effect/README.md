# Doppler Effect

An interactive physics simulation designed to help students explore the Doppler Effect and understand how relative motion between a wave source and an observer affects the observed frequency.

## 🌐 Live Demo

Explore the simulation:

https://inam-alvi.github.io/inam-alvi-doppler-effect/

## 📖 About the Project

The Doppler Effect simulation is an interactive physics learning tool that demonstrates how the observed frequency of waves changes when there is relative motion between a wave source and an observer.

The simulation provides a visual representation of wavefronts and helps learners understand:

- Relative motion between source and observer
- Approaching and receding wave sources
- Compression of wavefronts
- Expansion of wavefronts
- Changes in observed frequency
- The relationship between motion and wave behavior

## ✨ Features

- Interactive Doppler Effect visualization
- Moving wave source
- Visual wavefront propagation
- Adjustable source motion
- Observation of frequency changes
- Approaching and receding motion scenarios
- Real-time interactive feedback
- Educational explanations
- Responsive interface
