# Unit Circle Trigonometry Simulation

An interactive mathematics simulation designed to help students explore sine, cosine, tangent, angles, and coordinates using the unit circle.

## 🌐 Live Demo

Explore the simulation:

https://inam-alvi.github.io/inam-alvi-unit-circle-trigonometry/

## 📖 About the Project

The Unit Circle Trigonometry Simulation provides an interactive visual environment for understanding the relationship between angles and trigonometric values on the unit circle.

The simulation supports learning about:

- Unit circle geometry
- Angles and coordinates
- Sine
- Cosine
- Tangent
- Quadrants
- Positive and negative angles
- Trigonometric relationships
- Reference angles
- Periodic behavior of trigonometric functions

## ✨ Features

- Interactive unit circle
- Dynamic angle exploration
- Visual sine and cosine relationships
- Tangent exploration
- Coordinate visualization
- Quadrant-based learning
- Interactive trigonometry demonstrations
- Responsive interface
- Designed for students and mathematics educators

## 🎓 Educational Purpose

This simulation supports mathematics and STEM education by providing a visual and interactive way to understand trigonometric functions through the unit circle.

It can be used as:

- A classroom teaching aid
- A student self-learning resource
- A visual revision tool
- An interactive trigonometry demonstration
- A supplementary resource for mathematics lessons

## 🛠️ Technologies

- HTML5

## 🚀 How to Use

No installation is required.

Open the live simulation in a modern web browser:

https://inam-alvi.github.io/inam-alvi-unit-circle-trigonometry/

Adjust the angle and explore the corresponding position, coordinates, and trigonometric relationships on the unit circle.
