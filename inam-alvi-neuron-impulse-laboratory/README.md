# Neuron Structure & Impulse Propagation Laboratory

An interactive biology simulation designed to help students explore neuron structure and understand how electrical impulses propagate through a neuron.

## 🌐 Live Demo

Explore the simulation:

https://inam-alvi.github.io/inam-alvi-neuron-impulse-laboratory/

## 📖 About the Project

The Neuron Structure & Impulse Propagation Laboratory provides an interactive visual environment for exploring the major structures of a neuron and the process of electrical impulse propagation.

The simulation is designed to support the study of:

- Neuron structure
- Dendrites
- Cell body (soma)
- Axon
- Myelin sheath
- Axon terminals
- Electrical impulse propagation
- Neural communication

## ✨ Features

- Interactive neuron structure visualization
- Exploration of major neuron components
- Visual representation of impulse propagation
- Interactive learning environment
- Educational biology demonstrations
- Responsive interface
- Designed for students and biology educators

## 🎓 Educational Purpose

This simulation supports biology and STEM education by providing an interactive way to visualize neuron anatomy and electrical impulse propagation.

It can be used as:

- A classroom teaching aid
- A student self-learning resource
- A visual revision tool
- An interactive biology demonstration
- A supplementary resource for biology lessons
