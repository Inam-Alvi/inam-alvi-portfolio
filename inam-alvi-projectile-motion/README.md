# Projectile Motion Simulator

An interactive physics simulation designed to help students explore projectile motion, trajectory, range, maximum height, velocity, and launch angle.

## 🌐 Live Demo

Explore the simulation:

https://inam-alvi.github.io/inam-alvi-projectile-motion/

## 📖 About the Project

The Projectile Motion Simulator provides an interactive visual environment for exploring the motion of a projectile and understanding how launch conditions affect its trajectory.

The simulation is designed to support the study of:

- Projectile motion
- Trajectory
- Launch angle
- Initial velocity
- Horizontal and vertical motion
- Maximum height
- Horizontal range
- Time of flight
- Gravity

## ✨ Features

- Interactive projectile trajectory visualization
- Adjustable launch conditions
- Exploration of launch angle and velocity
- Visual representation of projectile motion
- Interactive physics controls
- Educational learning environment
- Responsive interface
- Designed for students and physics educators

## 🎓 Educational Purpose

This simulation supports physics and STEM education by providing an interactive way to visualize projectile motion and understand the relationship between launch conditions and trajectory.

It can be used as:

- A classroom teaching aid
- A student self-learning resource
- A visual revision tool
- An interactive physics demonstration
- A supplementary resource for physics lessons

## 🛠️ Technologies

- HTML5
- CSS3

- Interactive physics visualization

## 🚀 How to Use

No installation is required.

Open the live simulation in a modern web browser:

https://inam-alvi.github.io/inam-alvi-projectile-motion/

Use the available controls to adjust the projectile's launch conditions and observe how its trajectory changes.
