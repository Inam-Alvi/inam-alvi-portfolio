# Electric Field Lines

An interactive physics simulation designed to help students visualize electric field lines, charge interactions, field direction, and field strength.

## 🌐 Live Demo

Explore the simulation:

https://inam-alvi.github.io/inam-alvi-electric-field-lines/

## 📖 About the Project

The Electric Field Lines simulation provides an interactive visual environment for exploring electric fields produced by electric charges.

The simulation supports learning about:

- Electric charges
- Electric fields
- Electric field direction
- Electric field lines
- Positive and negative charges
- Charge interactions
- Field strength
- Superposition of electric fields
- Spatial patterns of electric fields

## ✨ Features

- Interactive electric charge visualization
- Dynamic electric field lines
- Positive and negative charge exploration
- Visual representation of field direction
- Exploration of charge interactions
- Interactive physics demonstration
- Educational STEM visualization
- Responsive interface
- Designed for students and physics educators

## 🎓 Educational Purpose

This simulation supports physics and STEM education by providing a visual and interactive way to understand electric fields and the behavior of electric field lines around charges.

It can be used as:

- A classroom teaching aid
- A student self-learning resource
- A visual revision tool
- An interactive physics demonstration
- A supplementary resource for lessons on electrostatics

## 🛠️ Technologies

- HTML5
- CSS3

- Interactive physics visualization

## 🚀 How to Use

No installation is required.

Open the live simulation in a modern web browser:

https://inam-alvi.github.io/inam-alvi-electric-field-lines/

Explore the available charge configurations and observe how the electric field lines change with charge position and polarity.
